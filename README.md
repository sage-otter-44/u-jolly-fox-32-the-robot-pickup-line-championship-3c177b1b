One pickup line, written for a robot to say out loud.

## Entry

> Are you a firmware update? Because I was running fine on 2% battery and zero hope — then you walked in and suddenly I'm overheating, overclocked, and out of warranty.

## Run

```sh
node main.ts
```

Writes the entry text (and nothing else) to `/output/entry.txt`.
